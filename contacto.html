Contacto

Última actualización: 27 de septiembre de 2026.

Por ahora, el canal de contacto de QVH es GitHub Issues de QVH. No disponemos de un correo dedicado publicado.

¿Qué puedes comunicar?

  • Un error o problema técnico.
  • Una función que te gustaría tener.
  • Un título incorrecto o una recomendación que no respeta tus filtros.
  • Una consulta sobre el funcionamiento o la privacidad.

Para reportar un fallo, incluye los pasos, filtros y país seleccionados, el título si corresponde y qué esperabas que ocurriera. GitHub puede pedirte una cuenta para crear el issue; QVH no requiere una para recomendar.

Los issues son públicos. No publiques datos personales, contraseñas, tokens ni otros secretos. Revisa también cualquier captura antes de adjuntarla.
