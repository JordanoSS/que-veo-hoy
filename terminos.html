Términos de uso

Última actualización: 27 de septiembre de 2026.

QVH te ayuda a elegir qué ver. No transmite películas ni series, no vende suscripciones y no representa a las plataformas de streaming.

Recomendaciones y disponibilidad

Las recomendaciones son orientativas. Los metadatos de TMDB pueden contener errores o estar incompletos. La disponibilidad regional, proporcionada por JustWatch mediante TMDB, puede cambiar; comprueba precio, acceso y condiciones en el servicio elegido. No garantizamos encontrar un título para cada combinación de filtros.

Fuentes, marcas y enlaces

This product uses the TMDB API but is not endorsed or certified by TMDB. Las marcas Netflix, Disney+, Max, Prime Video, Crunchyroll y las demás mencionadas pertenecen a sus titulares. Los enlaces externos se rigen por las condiciones de sus respectivos servicios.

Uso razonable

Utiliza el servicio sin abusar deliberadamente de los endpoints, intentar acceder a secretos o interferir con otros usuarios. No eludas las validaciones ni satures la API mediante solicitudes automatizadas.

Cambios y continuidad

Podemos ajustar funciones y filtros para mantener el proyecto. El servicio depende de terceros y puede interrumpirse; no ofrecemos garantías absolutas de disponibilidad o exactitud. Estas condiciones no pretenden limitar los derechos que te correspondan por ley.

Comunica problemas o sugerencias mediante GitHub Issues de QVH.
